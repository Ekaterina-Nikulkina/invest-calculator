# Инвестиционный калькулятор

Веб-приложение для оценки российских акций и облигаций на соответствие консервативной инвестиционной стратегии.

**Ссылка на работающее приложение:** [invest-calculator-murex.vercel.app](https://invest-calculator-murex.vercel.app/)

## О проекте

Данный калькулятор помогает начинающему инвестору принять решение о покупке ценной бумаги. Пользователь вводит финансовые показатели из карточки бумаги в приложении Т-Инвестиции, а калькулятор проверяет их по заданным критериям и выдает итоговый вердикт: «ПОКУПАТЬ», «СПОРНО» или «НЕ ПОКУПАТЬ».

В основе проекта лежит консервативная стратегия, ориентированная на защиту капитала и получение стабильного дивидендного дохода. Целевая доходность привязана к текущей ставке ЦБ РФ (ставка + премия).

Ключевые особенности:

- Учет отраслевой специфики (пороги ROE различаются для банков, IT, нефтегазового сектора и т.д.).
- Учет типа облигации при оценке дюрации (для ОФЗ и корпоративных бумаг применяются разные пороги).
- Статус «нет данных»: если пользователь не знает какой-то показатель, критерий не считается красным флагом и не ломает вердикт.
- Выделение критичных критериев (например, высокий долг или низкий кредитный рейтинг), которые мгновенно перечеркивают покупку.
- Расчет «справедливой цены» (Fair Price) для дивидендных акций.

## Стек технологий

- **React 19** (функциональные компоненты, хуки `useState`, `useEffect`).
- **Vite** (сборщик проекта).
- **JavaScript (ES6+)** (бизнес-логика, методы массивов, замыкания).
- **CSS3** (кастомные свойства для темной/светлой темы, Grid, Flexbox, адаптивная верстка).
- **LocalStorage** (сохранение выбранной темы и истории последних проверок).

## Архитектура

Логика приложения полностью отделена от пользовательского интерфейса.

- `src/js/criteria.js` — конфигурация всех критериев оценки (пороги, подсказки, сообщения для пользователя).
- `src/js/evaluate.js` — движок, который фильтрует критерии по контексту, определяет их статус и формирует итоговый вердикт.
- `react-app/src/App.jsx` — React-компонент, отвечающий за сбор данных формы и визуализацию результатов.

Такое разделение позволяет легко добавлять новые критерии (достаточно добавить объект в `criteria.js`) и покрывать логику автотестами независимо от UI.

## Запуск проекта

Для запуска React-версии выполните в терминале:

```bash
cd react-app
npm install
npm run dev
```

Для запуска тестов бизнес-логики выполните:

```bash
node src/js/test.js

```
