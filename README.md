# Invest Calculator (Инвестиционный калькулятор)

Калькулятор для проверки акций и облигаций на соответствие консервативной инвестиционной стратегии.

## 🎯 О проекте

Пользователь вводит финансовые показатели бумаги (ROE, P/E, дивидендную доходность и т.д.), а калькулятор оценивает их по заданным критериям и выдает итоговый вердикт: **ПОКУПАТЬ**, **СПОРНО** или **НЕ ПОКУПАТЬ**.

Особенности:

- Учитывает ставку ЦБ РФ для расчета целевой доходности.
- Имеет статус «нет данных» — если пользователь не знает какой-то показатель, это не ломает вердикт.
- Выделяет критичные критерии (например, высокий долг или низкий рейтинг), которые мгновенно перечеркивают покупку.
- Рассчитывает «справедливую цену» (Fair Price) для дивидендных акций.
- Все данные для расчётов пользователь может взять из карточки бумаги в приложении Т-Инвестиции.

## 🛠 Стек технологий

- **JavaScript (ES6+)**: вся бизнес-логика (движок оценки).
- **Node.js**: для запуска автотестов движка.
- _(В планах)_ **React**: для создания пользовательского интерфейса.

## 🏗 Архитектура

Логика полностью отделена от UI.

- `criteria.js` — конфигурация всех критериев и порогов.
- `evaluate.js` — «движок», который фильтрует критерии, проверяет их и выдает вердикт.
- `test.js` — автотесты для проверки корректности расчетов.

## 🚀 Как запустить тесты

Убедитесь, что у вас установлен Node.js, затем выполните в терминале:

```bash
node src/js/test.js
```
